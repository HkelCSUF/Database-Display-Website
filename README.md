# Database-Display-Website
Displays data from databases onto a website.

### HOW TO BUILD

1. Download the repository.
2. run `npm i` in the terminal to install dependencies.
3. run `npm run build` to build the project
4. run `firebase init --only hosting` to build firebase
5. run `firebase deploy --only hosting` to deploy the project
6. open the webpage of the project.
